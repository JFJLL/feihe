# 看板口径修复与验证（2026-09-09）

## 本次修改

- 周 KPI 继承合并单元格的阶段、代理、月份、项目、渠道标签；空白区块重置继承。月度 KPI 修正费用、曝光、互动等列偏移，并保留项目和渠道。
- KPI 对照按完整范围选择源表目标与实际，不汇总 TTL、渠道、星盟和总项目。重复目标或实际显示待核对；成本和规模指标分别解释，爆文率不平均。
- 评论总表按表头识别月份区块，读取范围跟随工作表列数扩展。非标准日期保留原文和执行量，仅完整日期参与日趋势。7月异常记录不再除以7、8月合计执行量计算异常率。
- 内容方向与达人层级增加篇数、篇均互动、配对报价 CPE、有效样本数及筛选。报价和互动均有记录才参与 CPE，真实零值保留，零分母显示缺失。
- 移除无依据健康评分、效率雷达和转化漏斗，替换为数据覆盖与待办；折叠指标字典、移除首页待接入占位卡。点赞/收藏/分享构成不混入采集评论。

## 浏览器反馈修复

- 取消 dashboard 笔记查询的 500 篇上限，以及飞书蒲公英同步的近 90 天限制。全量去重后用于分布、月度产出与 TOP20，保留项目及用户所选条件的过滤。
- 达人源表优先读取补充的 R/S 场景列，缺失回退 L/M；存储保留源值，展示统一去掉数字序号和连接号。不能从二级场景猜测缺失的一级方向。
- 原数据库的指标列默认 0；新增来源指标记录，区分空值与真实 0。所有 dashboard 聚合与笔记查询共用同一标准化视图。历史默认 0 在没有来源证明时显示缺失；重新同步可确认真实 0。
- 散点提示展示标题、方向、作者及数值，支持方向筛选；移除遮挡邻近点的大面积透明命中区。阅读分布使用固定数量级区间，避免极端值把绝大多数记录挤进同一柱。
- 箱线图固定 260px 高度，支持鼠标、点击和键盘聚焦显示样本数、最小值、四分位、中位数及最大值。修正零值四分位计算。
- I+TI 趋势从 2025-12-31 开始；品牌搜索趋势按当前品牌的有效数值裁去首尾空月份，保留中间缺口与零值，展示全部有记录的品牌。
- 总览增加字段覆盖卡，达人效率列表控制高度；品牌动作记录改为独立整行，避免被相邻长表拉高。
- 品牌问题图改接同步的竞品问题收集表，按实际品牌及类别统计。缺失品牌或类别但有讨论的记录保留为未标注/未分类。原表没有 P0/P1/P2，不生成风险等级。
- 话题按名称合并不同情绪记录，移除接口前 16 条截断；“其他”单独计数，具体话题只出现一次并显示评论条数。
