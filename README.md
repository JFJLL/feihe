# 飞鹤启萃 · 社媒增长中台项目

本项目整合了飞鹤启萃在小红书平台上的内容资产管理、评论外显质检、负向舆情拦截、聚光投放分析、灵犀大盘洞察与 AI 报告自动编译链路。

---

## 快速上手

### 1. 启动 Web 管理中台
在项目根目录下双击 启动中台.cmd，或在终端执行：
  cd feihe-mvp
  node scripts/dev.mjs

浏览器打开：http://127.0.0.1:5173/

### 2. 离线千瓜底表打标
支持对千瓜 Excel 底表进行自动 SPU 与内容类型识别：
  python 一键打标.py "data/爱他美六月千瓜数据底表.xls"
  python 一键打标.py "data/飞鹤6月千瓜数据底表.xls"
