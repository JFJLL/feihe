## 页面现状与核心问题审查

### 1. 实际 URL 与页面标题
- **启萃参考**：`http://localhost:5173/projects/qicui?day=2026-10-15`，Title: `社媒增长中台`
- **美菱总览**：`http://localhost:5173/projects/meiling`，Title: `社媒增长中台`
- **美菱投流**：`http://localhost:5173/projects/meiling/ads`，Title: `社媒增长中台`
- **美菱内容**：`http://localhost:5173/projects/meiling/content`，Title: `社媒增长中台`
- **美菱设置**：`http://localhost:5173/projects/meiling/settings`，Title: `社媒增长中台`

### 2. 首屏高度浪费与 Toolbar 堆叠
- **问题**：在 1440×900 视口下，首屏自上而下依次堆叠：
  1. 顶部操作栏（`飞书快照 · 日报补充` + `重新加载` 按钮，高 ~50px）
  2. 标题卡片（`营销项目看板 美菱 双十一投放与内容执行` + 统计周期与时间，高 ~100px）
  3. 警告提示卡（`⚠️ 数据提示与注意事项 (13项)`，高 ~60px）
  4. 看板内部二级导航（`总览 | KPI进度 41 | 投放明细 14 | 执行优化 9 | 数据来源 6`，高 ~50px）
- **影响**：页面实际业务内容（指标卡片或明细表）在第一屏仅露出头部边缘，首屏有效数据面积不足 40%，极度浪费纵向空间。

### 3. 侧栏路由假跳转与组件复用问题
- **侧栏入口**：
  - `01 项目总览` (`/projects/meiling`)
  - `02 投流分析` (`/projects/meiling/ads`)
  - `03 内容管理` (`/projects/meiling/content`)
  - `04 项目设置` (`/projects/meiling/settings`)
- **真实表现**：
  - `/ads` 与 `/content` 并没有独立的业务视图组件，而是复用了 `CampaignBoard` 整个外壳。
  - 点击侧栏 `/ads` 仅等于将首页内部的 5 tabs 切换到「投放明细 14」；
  - 点击侧栏 `/content` 仅等于将首页内部 5 tabs 切换到「执行优化 9」；
  - 侧栏切换时，用户仍然看到完全相同的大标题、相同的数据提示栏和相同的 5 个 tab 按钮，产生严重的页面割裂与伪路由感。

### 4. 首页指标混杂与「卡表化」
- **总览指标卡数量**：首页平铺了多达 41 张指标卡片（全部统计期模式下）。
- **口径严重混杂**：
  - 7-8月考核 KPI（如自采 CTR、爆文率、CPE、ROI 等）
  - 618 历史复盘结案数据（如全渠道 GMV 1695万、结案 ROI 8.79）
  - 双11 实时投流日报（自采京东、自采天猫、星伴、京东对投 ROI）
  - 达人发布执行进度（线上初筛 1096、二核确认 117、已发布 50）
- 所有不同时期、不同层级、不同性质的指标混合罗列，既无核心北极星指标突出，也无分期对比或漏斗归纳。

### 5. 图表缺失严重（图表数量对比）
- **启萃首页参考**：
  - 平台广告消耗与项目总投入双折线走势图（含每日断点防伪造）
  - 每日平台广告消耗柱状图（带预算对比悬浮）
  - KFS 全渠道费用构成环形占比图
  - 电商漏斗转化柱状图 / 人群包 CPUV 排行榜 / 竞品人群渗透对比
  - 评论审核饼图 / 达人储备分层堆叠条形图 / 评论维护双指标条带 / SEO 关键词达成进度条
- **美菱当前页面**：
  - 整个总览页**仅有 1 处**纯 CSS 简易水平条形图（「渠道 / 版位消耗对比」，4 根条），**其余所有区域全部为纯数字卡片或原始表格**。
  - 投放分析与内容管理页均为 100% 纯 Table 罗列，零可视化图表。

## 结论与重构指导
审查结果完全验证了用户批评。重构需：
1. 精简首屏：压缩或整合大标题、去掉冗余警告条与重复 tabs，释放首屏高度；
2. 真实路由化：`/ads` 与 `/content` 必须成为专职的独立分析与工作台页面，不再复用同一套卡表外壳；
3. KPI 与投流/执行解耦：总览突出当期核心盘与进度，历史 KPI 与细分执行分流到专区；
4. 补齐可视化：引入与启萃对齐的走势图、渠道构成图与执行看板图表，摆脱单纯堆砌 Table 与 Card 的状态。
