# 完整范围与开发顺序

## 第一批：项目入口与首用

客户/部门维护与无权限联系路径；参与/负责/可见与客户/部门/负责人/状态筛选；卡片和紧凑列表、来源/周期状态；创建/编辑/资料共用Dialog表单；默认负责人、次要状态/识别色与业务扩展；中性/空白模板、字段驱动推荐和目标确认；轻量下一步、可选团队、真实发布就绪；统一上下文和页面框架。

## 第二批：数据、共享指标与看板

真实数据工作台（来源/数据集/同步记录/质量/关联指标）；保留分页、映射全批次校验和失败恢复；复用metric_definitions/metric_bindings，项目绑定、标准/私有、版本和影响范围；选指标→呈现→保存；统一入口与有限组件登记，单值/时间趋势/分组/明细/目标；日期及常用筛选/卡片独立周期提示；投放、评论、内容的来源到实际业务对象/图表链路。

## 第三批：报告、角色与启萃

同一指标及版本的确定性报告、周期、趋势、异常、来源/新鲜度、历史/导出；AI可选且按项目取数；配置者/使用者/查看者入口；生产身份信任边界默认拒绝未知身份、测试身份隔离，项目权限继续服务端验证；启萃图表/业务/报告保留并支持组件选择/布局；统一表单、日常页面和状态，1280/1440/768/390及打开控件。

## 第四批：真实产品路径验收

四场景完整页面链路与对账、角色返回、目标不复制、来源/指标/报告一致性；保留本轮重新运行的既有单元/API/Playwright与历史看板回归；收集真实自动化步骤/请求/页面/持久化/trace/截图与测量，明确真人/真实飞书/生产未验范围。

## 边界

不换库、不换框架、不拆服务、不删旧业务，不新建CRM/OA/ERP/流程引擎/任意SQL/无限画布。接口/数据处理仅为上述用户路径所需。未经授权不接触生产/客户数据、不部署、不合并。用户在当前会话明确授权每次完成修复与验证后提交推送，暂不合并；本轮沿用这条当前授权。原始指标、百分、比率样本、草稿/取消、日期、来源ID/映射和数据隔离全部是不可退化项。
