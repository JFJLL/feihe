## 复用的边界与实现

复用现有project_settings保存蓝图，metric_definitions/metric_bindings保存新项目的独立定义，中央指标计算和原看板发布处理器继续使用。只复制指标规则、字段契约、呈现方式和顺序；不复制来源/授权/账户/供应商、数据行、客户与品牌资料、成员、报告、真实目标或原日期/筛选。保留可访问的来源项目ID作为结构来源记录，数据集/原指标/文档ID不成为新项目绑定。未能迁移的历史业务组件明确计数，仍留在原项目，本阶段不能替代启萃组件登记。

多来源分组独立对应，字段名可以不同。百分比按明确元数据和既有单位状态转换处理；自动显示跟随新字段，手工历史百分比在新字段缺元数据时必须再次明确fraction/percentage_points，不猜数值大小。比率保留成对/独立、缺失规则和实际样本提示。

提取现有指标的prepare步骤，使复用时全部定义、绑定、审计和确认状态在现有数据库batch中写入；字段/权限校验发生在写前，项目/数据版本条件防止迟到确认，重复相同确认复用同一组ID。真实审计触发器失败后所有新增定义/绑定回滚，重试正常。没有换库或建立模板市场。

投放模板只复用字段角色和共享指标语义，重新绑定新数据集与指标ID；新文档得到500消耗、10000曝光、100点击、1.0%点击率，原文档仍300/4000/70/1.8%。没有复制真实广告账户。
