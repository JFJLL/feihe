## 2. 主审口径反馈逐项修复与实现细节

### 2.1 累计消耗 vs 累计产出（缺日断线不补 0）
- **问题归因**：若缺失日期后继续累加下一个已知数，在图表上若不处理会造成隐性横向插值补 0。
- **解决方案**：
  - 遇到缺失日（`raw === null`），当天的累计值严格置为 `null`，折线自然断裂，真实展现采集断档。
  - 只有遇到实际有效采集日时，才累加至前期实际总和。
  - 副标题明确注明实际采集覆盖天数（如 `已记录覆盖 14/18 天 · 遇缺日断线不作插值补零`）。
  - 指数与金额均保留真实小数精度，移除不恰当的 `Math.round()`。
  - 判定有效数据严格要求：`spendValidCount > 0 && outputValidCount > 0 && series.length >= 2`。

### 2.2 轴系对齐与副标题动态修正
- **问题归因**：当产出指标为成交 GMV（单位：元）时，GMV 与消耗均位于左轴，但原有副标题写死“右轴产出”。
- **解决方案**：
  - 根据 `series` 实际分配的 `axis` 属性动态生成副标题说明：
    - 若产出同为金额（左轴）：注明 `左轴 累计消耗与累计成交GMV (元)`。
    - 若产出为次数/人数（右轴）：注明 `左轴 累计消耗 (元) vs 右轴 累计展现量/互动量/订单量`。

### 2.3 散点分布真实 0 成本 / 0 ROI 保留与动态单位
- **问题归因**：原有过滤条件为 `xVal > 0 && yVal > 0`，导致真实的 0 消耗（产生免费点击 CPC=0）或真实 0 成交（有花费 ROI=0.00）被错误丢弃；且横轴硬编码货币符号“¥”。
- **解决方案**：
  - 放宽判定为 `xVal >= 0 && yVal >= 0 && Number.isFinite(...)`，合法保留真实零成本与零产出散点。
  - 动态格式化标签：横轴根据实际 `scaleUnit`（如“次”或“元”）添加单位，杜绝在曝光量上套用货币符号。
  - 标题调整为客观中立的 **“投放规模与单位成本/效率”**，移除因果推断性文案。

### 2.4 热力图无障碍交互、稳定 Readout 与空卡自适应隐藏
- **问题归因**：热力图仅靠 hover 悬停，触屏或键盘用户无法交互查看；且指标不足时强凑空卡。
- **解决方案**：
  - 热力图细胞转为语义化 `<button type="button" tabIndex={0}>`，支持 `onClick`、`onFocus`、键盘导航及屏幕阅读器 `aria-label`。
  - 面板右上角/状态区提供稳定的读数看板（`selectedHeatmapCell`），点击或聚焦即可持续读取日期、指标名称与具体带单位数值。
  - 缺值细胞统一置灰（`#f1f5f9`，虚线边框，内容显示“—”）。
  - 若数据集无成对指标（如散点不足 2 点），对应面板自动隐藏，不强凑空卡。

### 2.5 周阶段规模与加权效率严格口径
- **问题归因**：原逻辑只要存在部分天有数据就计算周效率，并误将局部均值当成全周均值。
- **解决方案**：
  - **周总消耗 (`weekSpend`)**：严格要求所选区间内该周所有天均有效（`validDays === calendarDays`），若有缺日则显示 `—` 并标明 `覆盖 X/Y 天 (含缺日)`，绝不以局部总额充当周总额。
  - **周加权效率 (`weightedEfficiency`)**：严格要求该周每一天均同时具备分子与分母数据（含合法的真实 0）。若周内缺任一天分母，加权效率严格返回 `null`，前端显示 `— (需全周完整采集)`。
  - 修正了原变量声明拼写。
  - 标题简化为业务语言 **“自然周阶段规模与加权效率”**，移除“4维效能洞察”、“杜绝不完整分母”等口号式说明。

### 2.6 消除模型硬编码（京东对投 CID / 30 日归因）与 CID/Commerce 汇总指标
- **问题归因**：模型中多处硬编码“京东对投CID”与“30日归因”，导致其他项目（如黄天鹅商销、品牌线、红猫等）被错标。
- **解决方案**：
  - 动态从 `dataset.label`、`dataset.note` 与 `metrics` 中提取业务标识，仅在原文确有 30 日归因时标明归因口径。
  - 针对 CID 与商销（Commerce）数据集，汇总 4 卡精准展示：**1. 周期累计总消耗**、**2. 周期成交 GMV**、**3. 周期累计订单量 (或展现/点击)**、**4. 周期综合 ROI**。
  - 为日常 4 核心指标卡增加真实分日时序微趋势（SVG Sparkline），旧 overview 保持原样不传。
