# 内容方向分析

<callout emoji="🥛">
**SUMMARY**
**【CPUV效率】：专家背书>居家清洁>流感换季>大促预热/双11>户外清洁**
居家清洁：内容围绕高频、具体的日常清洁需求，与用户日常生活息息相关，更易理解“什么时候用、为什么需要”。场景需求与产品用途衔接较直接，更容易激发进一步了解、选购的意愿，从而带来较低的CPUV。
流感换季：选题需求具有时效性，且是目前家长较为紧迫的需要去解决的痛点，用户更容易产生共鸣并主动了解解决方法
专家背书：虽然CPUV最低，为6.04，但UV为815，获量规模相对有限。因此无法判定该方向即为转化效率最优的方向
**【CPM效率】：户外清洁>大促预热/双11>居家清洁>流感换季>专家背书**
户外清洁：户外出行、旅行类内容场景感强、视觉画面丰富，内容可看性高
大促预热/双11：正处于双11期间，大促囤货类的内容易受用户关注，借助大促流量红利，可有效降低曝光成本、放大推广效果
**【CPE效率】：专家背书>流感换季>大促预热/双11>居家清洁>户外清洁**
专家背书：医生专家内容自带权威信任感，用户看完后更愿意评论提问、表达认可，互动意愿强
流感换季：流感防护正是当下强痛点话题，有同款焦虑的用户讨论欲强；加上CTR高，点进去的用户本身就带着需求，因此互动成本较低
**【CTR效率】：流感换季>居家清洁>户外清洁>大促预热/双11>专家背书**
流感换季：封面标题多直击“流感季”“宝宝防护”痛点，母婴人群焦虑感强，看到就会想点进去找解决方案；情绪驱动+强需求，点击意愿最强烈
居家清洁：居家场景用户代入感强，“厨房油污”“宝宝玩具消毒”这些具体场景就知道和自己有关，点击意愿高；且内容实用性强，用户愿意点进去看具体的解决方案
**LEARNING**
流感换季是“种草引擎”：强时效+强焦虑驱动，CTR 和互动双高，用户点进来本身就带着需求，适合做种草期拉点击、扩人群的主力内容。
居家清洁是“转化主力”：日常高频场景代入感强、决策门槛低，CPUV表现最优，适合做转化收口阶段的核心内容。
**NEXT STEP**
1. 本阶段投放预算重点向居家清洁+流感换季两个方向倾斜，确保转化效率保持最优
2. 后续内容上可根据投放目标，分配不同的内容方向的比重
</callout>
