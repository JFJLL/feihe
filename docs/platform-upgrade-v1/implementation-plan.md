## 2. 阶段性细化任务与依赖关系

### 阶段 1：P0 权限与数据安全整改
- [x] 1.1 实现服务端企业级多租户会话与鉴权核心 (`lib/api-auth.ts`, `lib/auth-context.ts`)，定义 `requireProjectAccess(request, projectId, action)`。
- [x] 1.2 替换固定公开用户，严禁非法/缺失 `projectId` 回退至 `qicui`。
- [x] 1.3 遍历覆盖所有 API 端点，对请求携带的项目及资源所属权施加严格验证。
- [x] 1.4 分离连接凭证（平台/组织管理员）与业务数据源，杜绝前端越权指定任意表格。
- [x] 1.5 修复 `importRows` 供应商全表清空缺陷，建立 `(project_id, source_id)` 级隔离。
- [x] 1.6 建立快照暂存与原子发布机制，防止分批同步中途失败导致不可用或数据损毁。
- [x] 1.7 拆分公开笔记事实与项目私有属性（报价、合作、分类、预算、备注），避免跨项目互相覆盖。
- [x] 1.8 移除 `GET /api/data-map` 中的静态 mock seed 覆盖逻辑，连接状态基于实测记录。
- [x] 1.9 针对内存缓存与 HTTP 缓存增加用户/组织/项目/版本维度键隔离。

### 阶段 2：通用客户、项目、成员与初始化流程
- [x] 2.1 数据库增加 `organizations`, `departments`, `clients`, `project_members`, `project_templates`, `project_onboarding` 等对象模型。
- [x] 2.2 确立平台管理员、项目管理员、编辑者、只读成员 4 级角色及权限矩阵。
- [x] 2.3 重构项目创建表单，移除强绑 SPU/品牌限制，优化颜色选择与状态一致性。
- [x] 2.4 分离业务状态（筹备/进行/结束/归档）与向导初始化状态（待选模板/待接数据/待首同/待定指标/已就绪）。
- [x] 2.5 交付 4 套开箱即用模板（通用数据工作台、内容营销、评论质检、投放分析）。
- [x] 2.6 实现创建后向导页面与初始化进度持久化。
- [x] 2.7 改造项目中心，支持多维筛选与通用指标卡片呈现。
- [x] 2.8 实现项目归档、恢复与安全删除生命周期。

### 阶段 3：统一飞书接入、数据集、映射与同步
- [x] 3.1 拆分连接、数据源、数据集与同步任务概念。
- [x] 3.2 实现交互式飞书接入流：链接类型自动解析（电子表格/多维表格/知识库节点）-> 权限探针 -> 工作表选择 -> 数据预览。
- [x] 3.3 规范化错误诊断（授权失效/无文档权限/表头异常/限流等）。
- [x] 3.4 交付可视化字段映射编辑器（支持主键定义、数值/金额/百分比转换、真实零值与空值区分）。
- [x] 3.5 接入通用活动执行表等非社媒数据集，打通端到端读写。
- [x] 3.6 实现分页获取、并发锁、版本快照与幂等防重。
- [x] 3.7 构建轻量可靠的任务运行记录与调度状态呈现。
- [x] 3.8 完善数据源暂停、解绑与清理流程。

### 阶段 4：统一指标计算与可配置看板
- [x] 4.1 统一指标定义、字段绑定与计算公式引擎 (`lib/metrics/`)。
- [x] 4.2 统一聚合计算：求和、去重计数、同范围分子分母比率、分组统计。
- [x] 4.3 显式区分缺失、无数据、真实为零、不可计算状态。
- [x] 4.4 实现动态看板配置架构（草稿/发布版本、卡片增删改、并发版本冲突控制）。
- [x] 4.5 各模板提供定制化看板布局，彻底解耦硬编码社媒 JSX 布局。
- [x] 4.6 移除固定业务结论与硬编码品牌归一化。
- [x] 4.7 报告与 AI 能力复用统一指标引擎和权限上下文。

### 阶段 5：UI、导航和交互统一
- [x] 5.1 统一全站设计规范与视觉语言（间距、字号、圆角、阴影）。
- [x] 5.2 规范化表单输入组件、自定义下拉与紧凑预设调色器。
- [x] 5.3 重构导航架构（概览、数据、业务模块、报告、设置）。
- [x] 5.4 完善空状态、加载中、错误、未授权、未保存警告等状态体验。
- [x] 5.5 全面替换原生 confirm/alert，引入规范化二次确认对话框。
- [x] 5.6 响应式与键盘可访问性验证。
- [x] 5.7 捕获本地真实运行截图证据。

### 阶段 6：启萃迁移、对账与恢复

- [x] 6.2 提取启萃历史映射与定制规则至专用适配层。
- [x] 6.3 编写可重复执行的增量迁移脚本与备份回滚方案。
- [x] 6.4 运行新旧链路指标对账，确认 100% 数据一致性。
