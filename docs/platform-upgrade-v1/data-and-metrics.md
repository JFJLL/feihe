# 统一数据接入与指标计算口径规范 (Data & Metrics)

## 1. 核心领域对象层级

- **外部连接 (Connections)**: 组织/平台级配置，保存飞书 App ID / App Secret，仅管理员可见。
- **数据源 (Data Sources)**: 项目级绑定的具体表格或文档，关联特定连接。
- **数据集 (Datasets)**: 经由可视化字段映射与数据清洗后的结构化数据，提供给指标计算引擎消费。
- **指标定义 (Metric Definitions)**: 包含统计口径、聚合方式（sum/count/distinct_count/ratio）、单位、过滤条件及空值策略的标准定义。
- **看板 (Dashboards & Cards)**: 声明式的看板草稿与发布版本，由若干配置化图表卡片组成，消费统一指标引擎。

## 2. 字段映射与数据转换规则

- **支持字段类型**: `text`, `number`, `currency`, `percentage`, `date`, `boolean`, `category`。
- **数值与比率计算安全准则**:
  - 严禁简单使用 `Number()` 盲目转换，针对金额符号（`¥`、`$`）、千分位逗号（`,`）、百分号（`%`）进行规范化预处理。
  - **真实零值 vs 缺失空值**: 空单元格标记为 `null`，不盲目填充为 `0`；零值（如 `0`、`0%`）按真实数值 `0` 参与统计。
  - **比率类指标统一算法**: 分子求和除以分母求和，作用于相同时间范围与相同过滤条件构成的样本集，**严禁对逐行比率取算术平均值**。
  - **分母为零处理**: 当分母为 0 或无有效样本时，指标返回 `null` 并附带说明“样本量不足”，前端友好展示占位，不伪造 `0%` 或抛出 `NaN`。

## 3. 供应商交付数据按源隔离机制

- 取消旧有 `DELETE FROM supplier_comments WHERE project_id=?` 全量清空逻辑。
- 引入 `source_id` 字段维度，主键与业务唯一索引升级为 `(project_id, source_id, external_key)`。
- 采用快照暂存与批量发布事务机制：读取 -> 暂存校验 -> 校验通过 -> 仅更新或替换所属 `source_id` 下记录。
