# 关键业务用户路径验证 (USER FLOWS)

## 路径 A：新部门从零开始接入业务与度量

```mermaid
graph TD
    A[项目中心: 点击新建项目] --> B[选择业务模板: 通用数据工作台]
    B --> C[填写项目名称与负责部门, 选定识别色]
    C --> D[保存并自动进入新项目初始化向导]
    D --> E[向导步骤2: 直达设置-数据源配置]
    E --> F[粘贴飞书表格或多维表格链接]
    F --> G[智能检测工作表/数据表并确认]
    G --> H[点击立即同步: 数据真实落入 datasets 与 dataset_rows]
    H --> I[返回项目总览: 查看动态生成的业务指标卡与明细表]
    I --> J[点击自定义看板: 自定义添加转化率/进度卡片并发布]
    J --> K[进入成员管理: 添加协作成员并分配管理员/编辑者/观察员]
    K --> L[点击完成初始化: 项目正式发布进入就绪状态]
```

### 真实操作体验保障：
1. **无需理解底层代码**: 用户不需要了解 Sheet ID、范围（A1:AZ5000）或 JSON 映射规则，直接贴链接智能探测并下拉选择工作表；
2. **直达任务目标**: 所有向导按钮均直达对应的功能 Tab，无需二次导航；
3. **真实数据展现**: 同步完成后即可在看板中实时计算出指标，并能在“数据明细”中直接检索和分页查看原始记录；
4. **多成员分权协作**: 管理员、业务编辑者与只读成员权限边界清晰，敏感配置受控。
