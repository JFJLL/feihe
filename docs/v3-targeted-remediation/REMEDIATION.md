# 修复说明

## 指标配置与计算

记录计数统计行数；字段非空数和字段去重数使用独立的聚合枚举与字段选择。配置判别集中在 metrics/config：显式自定义聚合优先；UI 切换聚合清除旧 metric 模板绑定。

全盘和分组共用 evaluateMetricRows。旧指标定义的 min/max 继续使用最小/最大聚合，避免统一计算造成兼容回归。空值默认跳过，平均值使用有效样本量；补零是显式规则。10/null 得到全盘 10、同组 10、样本 1。比率区分缺字段、全空、真实零、非法数值与零分母；没有观测分子时显示不可计算，明确补零才允许缺失为 0。非法符号、布尔与畸形数值不强转零。

预览与发布共同校验项目的数据集归属、字段、数值类型、分子分母、分组、日期与展示兼容性。模板指标所需字段也校验。日期与全部配置保存在 configJson，GET 后重新编辑完整回填。旧 bar_chart 按既有 dimension 回填分组。

预览、数据明细与看板指标按当前请求配置匹配结果；新配置立即失效旧正常值。请求有版本控制/AbortController，迟到响应忽略，失败展示错误。批量指标中无效卡明确返回错误，其他合法卡仍可计算。

## 草稿、保存和导航

看板配置加载与数据集目录/明细分离。数据集切换、搜索、翻页及同步不会重置 draftCards。
saveDashboard 返回明确 boolean；仅成功响应之后执行待定切换或导航。409、500 与请求断开均保留数据集、草稿和编辑态。

保存锁冻结提交快照、禁用重复操作；服务端确认后采用其 dashboardId、version 与 cards。冲突直接读取响应 serverVersion。接口执行版本条件更新与事务内卡片替换，添加内部 save_token 确认本次提交，updated_at 保持 ISO 时间。空数组是合法看板，不恢复默认卡。

取消编辑从 publishedCards 恢复；模块链接、项目切换、beforeunload 和浏览器后退处理未保存修改。强制覆盖与放弃草稿明确区分，保存过程中的按钮受忙状态约束。

## 来源、映射和导入

链接一变即推进请求版本并取消旧 inspect；关闭、编辑其他来源、换项目、隐藏来源页也使旧请求失效。
映射绑定项目、解析后的文档 token、sheet/table ID、字段名/类型及多维表字段 ID。改变表或字段结构清理旧规则并显示当前表预览。

预览和 importRows 共用 field-mapping 纯转换。必填与主键在补值之前校验；多个主键采用复合键，空值和重复都拒绝整次导入。类型、日期格式与空值策略都有实际执行；暂不支持跳过数据行，前端无该选项，服务端明确拒绝旧无效配置。

布尔仅接受明确真/假文本；未知值报错。非法数值/日期报错；数值推断检查所有可见有效样本，空值默认保留 null。日期分隔符转换不破坏 ISO 小数秒。未映射字段继续保留且补入 columns；name 是显示名，key 用于取值。

电子表格同步按真实行列元数据分块读取全表；显式范围返回 limited_range 并在来源页面展示，空范围展示全表。
多维表表/字段元数据与记录均检查分页完整性；has_more=true 缺 token、重复 token 或畸形记录报错，保留先前快照。全量指标不依赖页面 500 行预览限制，501 行加权 16.7% 回归保留。

批量同步直接调用接收已验证 ProjectAuthContext 的内部服务，不重新构造 HTTP 请求。单源、批量及启萃历史分支记录真实 actor_user_id；只读和无权身份仍拒绝。暂存发布、来源血缘与合法用途校验继续使用原有流程。

## 日期与分页

卡片编辑有日期字段、开始/结束入口。范围经过试算、发布、GET、刷新和重开；使用 project_settings 的 timezone，默认 Asia/Shanghai。日期解析为时间点，结束日使用下日零点作为排除边界；无日期/非法日期记录不进入指定周期。小数秒、显式时区与 DST 非法时间有反例。

同步/数据更新只更新数据目录和明细版本。当页超过总页数，先校正页号再重新请求。表头使用 column.name，单元格读取 row[column.key]；amount / 金额 显示 100。

## 初始化、授权与 UI

初始化前端按钮和服务端均读取实际来源/数据集、同步数据、合法指标卡与成员情况。单人可显式跳过团队；稍后配置只是隐藏向导，不发布。项目资料保护、角色与工作空间刷新保留。

归档项目仅为授权管理员的 restore 操作建立例外；其他写入与只读恢复仍拒绝。页面经过归档、刷新、恢复、编辑、发布及再刷新。

CardEditModal、映射、未保存、冲突及确认共用原生 showModal Dialog：可访问名称、进入/限制/恢复焦点、Escape、固定操作区及内部滚动。390px 有打开状态的真实几何与键盘断言。CustomSelect 继续复用。

数据导航 URL、标签与内容一致。评论质检使用现有评论运营与处置主体；投放分析使用广告消耗趋势及点击效率主体。启萃/营销的丰富历史图表沿用既有模块，并执行七段既有回归。

接口与计算修改限于以上行为，数据库增加审计操作者与保存确认列，没有更换数据库或拆服务。
