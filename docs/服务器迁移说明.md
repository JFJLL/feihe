# 飞鹤社媒增长中台迁移说明

## 包内内容

- `feihe-mvp/`：完整站点源码、D1 数据库结构与迁移、R2/接口逻辑、公开站点配置。
- `config.json`：飞书、OSS、小红书等本地明文配置。
- `token.txt`：OSS Cookie 池的本地缓存。
- 根目录 Python 脚本：评论抓取、笔记抓取、关键词打标与配置加载。
- Excel、HTML、Word 参考材料以及 `outputs/` 已生成结果。
- `feihe-mvp/.wrangler/`：本机开发环境的 D1/R2 状态，便于继续本地调试。

## 未打包内容

为控制体积并避免跨机器二进制不兼容，未包含以下可重建内容：

- `feihe-mvp/node_modules/`
- `feihe-mvp/dist/`、`.next/` 和 Vite 缓存
- Git 历史与系统缓存文件

## 在新服务器继续开发

1. 安装 Node.js 22.13 或更高版本，以及 pnpm。
2. 进入 `feihe/feihe-mvp/`。
3. 执行 `pnpm install`。
4. 开发运行：`pnpm dev`；生产构建：`pnpm build`。

`scripts/dev.mjs` 会从上一级目录读取 `config.json`。Keystone 生产密钥保存在 Sites 托管环境中，不会由托管平台回传明文；如脱离当前 Sites 环境部署，请在新服务器环境变量中设置：

- `KEYSTONE_API_KEY`
- `KEYSTONE_BASE_URL=https://keystonehk.ai/v1`
- `KEYSTONE_MODEL=gpt-5.6-terra`
- `KEYSTONE_IMAGE_MODEL=gpt-image-2`

压缩包包含敏感凭证，请只通过可信渠道传输，并限制文件读取权限。


## 生产部署

1. git pull; pnpm install; pnpm build.
2. 复制 config.json、token.txt、.wrangler（停服后拷）。
3. pnpm start:prod（5013）。不要在线上跑 dev。
4. 首启自动生成 data/local.db（有 .wrangler 则自动搬运旧数据），git 外，记得备份。
5. 免登录查看加 PUBLIC_SITE_ACCESS=true（只读）。
